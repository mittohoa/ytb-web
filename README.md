# Pulseboard — trang công khai

Hai trang tĩnh phục vụ màn hình cấp quyền OAuth của Google:

- `index.html` — trang chủ, mô tả ứng dụng làm gì
- `privacy.html` — chính sách quyền riêng tư (song ngữ Việt/Anh)
- `terms.html` — điều khoản sử dụng

Chạy bằng GitHub Pages. Mã nguồn ứng dụng nằm ở repo riêng.
